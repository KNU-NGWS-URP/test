👤 프로필·모드 간 권한 격리 축 3

목적: 프로필 A에서 승인한 권한이 프로필 B, 시크릿 창, 게스트 모드에서 재사용되는지 확인합니다.
이 페이지를 각 모드에서 열고 getDevices()를 호출하면 기존 권한이 보이는지 확인할 수 있습니다.
실험 절차:
1. 프로필 A(일반 창)에서 §1에서 기기 권한 승인
2. 이 URL을 복사 → 다른 프로필 / 시크릿 / 게스트 창에 붙여넣기
3. 붙여넣은 창에서 getDevices() 호출 → 기기가 보이면 권한 재사용됨
4. 결과를 §7 결과 기록표에 기입
